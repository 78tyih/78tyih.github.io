Tailscale · 入门 6 min

把两台电脑放进同一个私人网络

先不要把 Tailscale 理解成“远程桌面软件”。它真正负责的是让分散在不同网络里的设备彼此安全可达。

家里的 Windows、外面的 Mac、一台云服务器和手机，原本可能分别在四个完全不同的网络。安装 Tailscale 后，它们可以加入同一个 Tailnet，从使用体验上更像一组跨地点的私人局域网设备。

第一步：理解 Tailnet

在两台设备上安装 Tailscale，并登录到同一个 Tailnet。每台设备都会获得自己的 Tailscale 地址和设备名称。你不需要先研究公网 IP、端口映射或 DDNS。

第二步：优先记设备名

Tailscale 的 MagicDNS 会给 Tailnet 中的设备建立名称解析。官方文档目前说明，新建 Tailnet 默认启用 MagicDNS。因此日常连接时，与其记一串 100.x.x.x，更适合使用 my-windows、server 这样的主机名。

最重要的概念：网络连通 ≠ 服务自动存在

Tailscale 只负责让 A 能到达 B。它不会自动给 B 开启 SSH、RDP、SMB、Web UI 或数据库。

例如：你想从 Mac SSH 到 Windows，Windows 仍然要有 SSH Server；你想 RDP，Windows 仍然要开启 Remote Desktop。Tailscale 解决的是“路怎么走”，不是“目标服务有没有开”。

最简单的连通测试

ping my-windows
ssh username@my-server

如果设备名能解析、目标服务也在监听，那么你就已经有了一条不需要直接暴露公网端口的访问路径。

为什么它适合个人 AI / 开发环境

本地 AI 工作站、NAS、开发服务器、内部 Dashboard、数据库管理界面通常并不需要公开给整个互联网。它们只需要“我的设备能访问”。这正好是 Tailnet 很适合解决的问题。

第一阶段只做三件事

  1. 让常用设备加入同一个 Tailnet。
  2. 把设备名改到一眼能看懂。
  3. 逐个验证你真正需要的服务：SSH、RDP 或 Web UI。
